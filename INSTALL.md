QuizForge: answer feedback on Next/Finish button

Replace ONLY lib/main.dart in your existing QuizForge project.
Do not replace your database, Gemini service, API key or pubspec.yaml.

The selected answer flashes green/red for 700ms only after Next question or Finish quiz is pressed, when the setting is enabled.

Run flutter analyze and then flutter run with your existing gemini_config.json.
