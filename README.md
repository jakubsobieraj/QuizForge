# QuizForge — Flutter starter

Quiz application for CS32005.

## What's implemented
- Create multiple-choice questions with subject, four answers, and correct choice
- Subject-based quiz selection, random question order, scoring and answer review
- SQLite persistence for questions and quiz history
- Input validation, basic error handling
- Four unit tests for scoring

## How to run
1. Install Flutter SDK and Android Studio, then run `flutter doctor`.
2. In a terminal, run `flutter create quizforge` to generate a standard Android/Flutter project.
3. Copy this starter's `lib/`, `test/`, and `pubspec.yaml` into the new `quizforge/` folder, replacing the generated files.
4. Run `flutter pub get`.
5. Start an Android emulator (or connect a phone with USB debugging enabled).
6. Run `flutter run`.
7. Run tests with `flutter test`.
